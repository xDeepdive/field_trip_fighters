# Creating a GitHub Release

## Quick Steps

1. **Go to your GitHub repo:**
   ```
   https://github.com/xDeepdive/field_trip_fighters
   ```

2. **Create a Release:**
   - Click "Releases" (right sidebar)
   - Click "Create a new release"
   - Tag: `v0.53.1-beta`
   - Title: `Field Trip Fighters - Browser Multiplayer Beta`
   - Description:
     ```
     🎮 Browser-based fighting game with online multiplayer!

     ## Features:
     - 5 playable characters
     - WebSocket multiplayer
     - Auto-matchmaking
     - HTML5 (runs in browser)
     - Mobile compatible

     ## Quick Start:
     See QUICK_START_BROWSER.md for deployment instructions

     ## Server:
     Deploy server/ to Render.com (free tier)

     ## Game:
     Export to HTML5 and deploy to Netlify

     Ready for Solana token integration!
     ```

3. **Attach the zip:**
   - Upload the zip file from your computer
   - OR let GitHub auto-generate source code zip

4. **Publish Release**

5. **Share the link:**
   ```
   https://github.com/xDeepdive/field_trip_fighters/releases/tag/v0.53.1-beta
   ```

Anyone can download the zip from there!
